# Lin4Neuro WSL2 版 インストール手順

## 前提条件

- Windows 11
- WSL2 がインストール済みであること
  - 未インストールの場合は、管理者権限の PowerShell で以下を実行してください
    ```
    wsl --install
    ```
  - インストール後、PC の再起動が必要です

## 必要なファイル

以下の 2 つのファイルを入手してください。

1. `abis-2027-wsl2.tar.gz` (Lin4Neuro 本体)
2. `setup.bat` (インストールスクリプト)

## インストール

### 1. ファイルの配置

NTFS でフォーマットされた外付けディスク（または内蔵ディスク）に、**2 つのファイルを同じフォルダに保存**してください。

- 例: `E:\` に `abis-2027-wsl2.tar.gz` と `setup.bat` を配置

> **注意**: exFAT や FAT32 でフォーマットされたディスクでは正常に動作しない場合があります。必ず NTFS でフォーマットされたディスクを使用してください。

### 2. setup.bat の実行

PowerShell またはコマンドプロンプトから `setup.bat` を実行します。

```
E:\setup.bat
```

あるいは、エクスプローラーで `setup.bat` をダブルクリックしても実行できます。

インストールが完了すると、`setup.bat` と同じドライブの `\Lin4Neuro` フォルダ（例: `E:\Lin4Neuro`）にディストリビューションがインストールされます。

## 使い方

### 1. WSL2 の起動

PowerShell またはコマンドプロンプトから以下を実行します。

```
wsl -d Lin4Neuro
```

### 2. xrdp の起動

WSL2 のターミナルが開いたら、以下のコマンドで xrdp を起動します。

```
start-xrdp.sh
```

以下のメッセージが表示されれば、xrdp の起動は成功です。

```
============================================
 xrdp が起動しました
 Windows のリモートデスクトップで接続:
   アドレス: localhost:3390
   ユーザー名: brain
   パスワード: lin4neuro
============================================
```

### 3. リモートデスクトップで接続

Windows の「リモートデスクトップ接続」を起動し、以下の情報で接続します。

| 項目 | 値 |
|------|-----|
| コンピューター | `localhost:3390` |
| ユーザー名 | `brain` |
| パスワード | `lin4neuro` |

> **リモートデスクトップ接続の起動方法**: Windows キー を押して「リモートデスクトップ接続」と入力するか、`Win + R` で「`mstsc`」と入力して実行してください。

接続すると、Lin4Neuro のデスクトップ環境が表示されます。

## アンインストール

Lin4Neuro を削除するには、PowerShell またはコマンドプロンプトから以下を実行します。

```
wsl --unregister Lin4Neuro
```

これにより、WSL2 からディストリビューションとインストール先のフォルダが自動的に削除されます。
